# 어차피그린 (Anyway Green)

대학 간 친환경 공동캠페인 **어차피그린** 파일럿 웹사이트 (ESG PBL 팀 프로젝트)

- `index.html` — 사이트 전체 (그린 테스트 · 신청 · 미션 인증 · 랭킹 · Tip Exchange · 운영자 화면)
- `supabase_setup.sql` — 데이터베이스 설정 (Supabase SQL Editor에서 1회 실행)
- `배포가이드.md` — 배포·운영 방법

## 수정하는 법
1. GitHub에서 `index.html`을 열고 연필(✏️) 아이콘 → 수정 → **Commit changes**
2. 1~2분 뒤 Vercel이 자동으로 다시 배포합니다.

문구·미션은 `index.html`의 `2. 콘텐츠` 부분, 일정·상한은 운영자 화면 > 설정에서 바꿉니다.

**배포 주소:** https://anywaygreen.vercel.app
